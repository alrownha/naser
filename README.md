# Forex Sniper Web App

This is a simple full stack Node.js application that allows a user to login with predefined credentials and upload a screenshot of a forex chart. The system performs a very basic image analysis and displays a placeholder "sniper trading" suggestion.

## Usage

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   node index.js
   ```
3. Open your browser to `http://localhost:3000` and login using:
   - **Username:** `trader`
   - **Password:** `sniper`

4. Upload a chart image to receive a trading suggestion.

This is intended as a demonstration only and should not be used for real trading decisions.
